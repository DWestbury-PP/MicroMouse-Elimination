# MicroMouse Grand Prix

Browser-based MicroMouse elimination championship prototype.

Open `index.html` in a modern browser. No build step required.

Four independent mice compete on a 16×16 maze, using sensor-based discovery and flood-fill navigation. The prototype includes configuration tuning, exploration, return-to-start and speed-run phases, a two-round elimination tournament, and a local leaderboard.

Times are simulated, not hardware measurements. The current leaderboard is local rather than server-verified.
